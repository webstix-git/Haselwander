# Haselwander Real Estate LLC

Next.js website for Haselwander Real Estate LLC — residential, commercial, office space, and investment properties in the Chippewa Valley.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — run ESLint

## Deploy

Optimized for [Vercel](https://vercel.com). Connect the repository and deploy with the Next.js framework preset.
